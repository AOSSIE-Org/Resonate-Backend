# Contributing to Resonate Backend

Thank you for considering contributing to the Resonate Backend project! We welcome contributions of all kinds, including bug fixes, new features, and documentation improvements.

## How to Contribute

### 1. Fork the Repository
- Fork the repository to your GitHub account.
- Clone your forked repository locally:
  ```bash
  git clone https://github.com/aditi25srivastava/Resonate-Backend.git
  cd Resonate-Backend 

### 2. Create a Feature Branch
- Always create a new branch for each feature or bugfix.
- Use a descriptive branch name, for example:
git checkout -b Add-Missing-IDs-and-Restructure-Issue-Templates


### 3. Make Your Changes
- Add, edit, or delete files as needed to implement your changes.
- Stage and commit your changes with clear commit messages:
git add .git commit -m “Describe your change clearly”


### 4. Push Your Branch
- Push your feature branch to your fork on GitHub:
git push origin Add-Missing-IDs-and-Restructure-Issue-Templates


### 5. Open a Pull Request
- Go to the original repository on GitHub.
- Click the "Compare & pull request" button.
- Select your feature branch and target the correct base branch (`dev` or `main`).
- Fill out the pull request template and explain what you did.

### 6. Respond to Reviews
- Be ready for feedback from the maintainers.
- Make changes in your branch if needed and push; the pull request will update automatically.

### 7. Celebrate!
- After your pull request gets merged, your contribution will become part of the project!

---

For questions, open an issue or start a discussion.

Happy coding!!!
